# Gestor-Facil-ERP
Sistema de gestão empresarial (mini ERP) desenvolvido com JavaScript puro (Vanilla JS), HTML5 e CSS3. Inclui controle financeiro, CRM com CPF e endereço completo, controle de estoque com histórico de auditoria, vendas integradas, agendamentos, caderneta digital, relatórios, perfil com foto e módulo preparatório de Notas Fiscais (NF-e, NFC-e e NFS-e) via LocalStorage.
